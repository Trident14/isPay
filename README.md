# isPay Banking App Frontend

This is the isPay Banking App Frontend application with JWT authentication and a redesigned, fully responsive layout. The project includes a modern side navigation bar, and is optimized for both desktop and mobile devices.

## Features

- **JWT Authentication**: Users can register, login, and receive a JWT token stored in an HttpOnly cookie for secure authentication.
- **Responsive Design**: The side navigation bar and layout adjust to fit both mobile and desktop screen sizes using Tailwind CSS.
- **Side Navigation Bar**: A sleek and intuitive sidebar that collapses on mobile for improved navigation.
- **Savings Goal Feature**: Ensures transfers happen even when low on balance and allows users to save for future goals.

## Technologies Used

- **React**: For building the user interface.
- **Tailwind CSS**: For styling and making the layout responsive.
- **JWT (JSON Web Token)**: For handling authentication and protecting routes.
- **Context API**: For managing global state like user authentication.
- **Vite**: For fast development and bundling.
